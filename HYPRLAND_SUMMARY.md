# Hyprland Lua Config Migration — Summary

Hyprland deprecated hyprlang (`hyprland.conf`) in favor of a Lua config (`hyprland.lua`), introduced **2026-04-26** on `git`, shipped stable in **0.55.0**; current stable is **0.56.0**.

## Files

| File | Status | Notes |
|------|--------|-------|
| `hyprland/.config/hypr/hyprland.lua` | NEW | Active config (loaded if present) |
| `hyprland/.config/hypr/hyprland.conf` | FALLBACK | Loaded only when `.lua` is absent |
| `hyprland/.config/hypr/monitors.conf` | unused | Generated by nwg-displays (2026-03-17) |
| `hyprland/.config/hypr/workspaces.conf` | empty | — |
| `context.md` | updated | Migration reference |

## Architecture

- `hyprland.lua` and `hyprland.conf` are **mutually exclusive** (checked once at startup).
- `hyprland.lua` wins if present; delete/rename it to roll back.
- Requires Hyprland ≥ 0.55.

## Bind mapping (selected)

| Area | hyprlang | Lua |
|------|----------|-----|
| Vars | `$mainMod = ALT` | `local mainMod = "ALT"` |
| Terminal | `exec, $terminal` | `hl.bind(mainMod.." + T", hl.dsp.exec_cmd(terminal))` |
| Close | `killactive` | `hl.dsp.window.close()` |
| Float | `togglefloating` | `hl.dsp.window.float()` (action `toggle`) |
| Fullscreen 1 / 2 | `fullscreen, 1/2` | `hl.dsp.window.fullscreen({ mode="fullscreen" / "maximized" })` |
| Scratchpad | `togglespecialworkspace, magic` | `hl.dsp.workspace.toggle_special("magic")` |
| Mouse move | `bindm = ... mouse:272, movewindow` | `hl.bind(..., hl.dsp.window.drag(), { mouse = true })` |
| Media (locked+repeat) | `bindel = ,...` | `hl.bind("...", ..., { locked=true, repeating=true })` |
| Workspaces 1–10 | `workspace, N` | `hl.dsp.focus({ workspace = i })` (loop) |
| Autostart | `exec-once =` | `hl.on("hyprland.start", fn)` |
| Env | `env = X, Y` | `hl.env("X", "Y")` |
